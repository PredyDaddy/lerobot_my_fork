# SmolVLA SO-101 部署指南

## 需要传输的文件

| 文件 | 大小 | 必需 |
|------|------|------|
| 代码仓库 | ~100M | ✅ |
| 训练权重 `outputs/train/smolvla_so101_6d/checkpoints/last/` | 865M | ✅ |
| VLM模型 `SmolVLM2-500M-Video-Instruct/` | 7.4G | ✅ |
| `smolvla_base/` | 873M | ❌ 不需要 |

---

## 1. 服务器打包

```bash
cd /mnt/data2/cqy/workspace/lerobot_my_fork

# 打包代码
tar --exclude='outputs' --exclude='SmolVLM2*' --exclude='smolvla_base' \
    --exclude='.cache' --exclude='*.mp4' --exclude='so101_v3_dataset*' \
    -czvf lerobot_code.tar.gz .

# 打包权重
tar -czvf smolvla_checkpoint.tar.gz outputs/train/smolvla_so101_6d/checkpoints/last

# 打包VLM
tar -czvf SmolVLM2.tar.gz SmolVLM2-500M-Video-Instruct
```

## 2. 传输

```bash
scp lerobot_code.tar.gz smolvla_checkpoint.tar.gz SmolVLM2.tar.gz user@机器人:/home/user/
```

## 3. 目标机器解压

```bash
cd /home/user
mkdir lerobot && cd lerobot
tar -xzf ../lerobot_code.tar.gz
tar -xzf ../smolvla_checkpoint.tar.gz
tar -xzf ../SmolVLM2.tar.gz
```

## 4. 修复路径

```bash
export REPO_ROOT="/home/user/lerobot"
export CKPT="${REPO_ROOT}/outputs/train/smolvla_so101_6d/checkpoints/last/pretrained_model"

# 修复 config.json
sed -i "s|/mnt/data2/cqy/workspace/lerobot_my_fork|${REPO_ROOT}|g" ${CKPT}/config.json

# 修复 preprocessor
sed -i "s|/mnt/data2/cqy/workspace/lerobot_my_fork|${REPO_ROOT}|g" ${CKPT}/policy_preprocessor.json
```

如不想改文件，也可以在运行推理时直接指定：

```bash
POLICY_DIR="${CKPT}" VLM_MODEL_PATH="${REPO_ROOT}/SmolVLM2-500M-Video-Instruct" \
ROBOT_PORT=/dev/ttyUSB0 bash so101_scripts/infer_smolvla.sh
```

## 5. 安装环境

```bash
conda create -y -n lerobot python=3.10
conda activate lerobot
pip install -e ".[smolvla]"
```

## 5.1 系统依赖与权限

```bash
# 视频编码工具（用于写入 eval 数据集视频）
sudo apt-get update && sudo apt-get install -y ffmpeg

# 串口/相机权限
sudo usermod -aG dialout,video $USER
# 重新登录后生效
```

## 6. 运行推理

```bash
ROBOT_PORT=/dev/ttyUSB0 bash so101_scripts/infer_smolvla.sh
```

## 6.1 相机与空相机说明

- 真实相机：`top` + `wrist` 两路（通过 `rename_map` 映射到 `camera1/2`）。
- 空相机：推理时通过 `--policy.empty_cameras=1` 自动补一张 `empty_camera_0`，无需配置实体相机。
- 目的：对齐 SmolVLA base 预训练时的 3 路视觉输入，保持训练/推理一致性。

### 可选参数

```bash
# 指定相机
TOP_CAM_INDEX_OR_PATH=0 WRIST_CAM_INDEX_OR_PATH=2 \
ROBOT_PORT=/dev/ttyUSB0 bash so101_scripts/infer_smolvla.sh

# 指定checkpoint
CHECKPOINT_STEP=30000 ROBOT_PORT=/dev/ttyUSB0 bash so101_scripts/infer_smolvla.sh

# 指定任务
TASK="Pick up the block" ROBOT_PORT=/dev/ttyUSB0 bash so101_scripts/infer_smolvla.sh
```
